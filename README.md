# UGC — прототип платформы

Интерактивный прототип UGC-платформы для российского рынка: продавцы заказывают у креаторов видео и фото по брифу.
«UGC» — временное нейтральное обозначение, не утверждённый бренд. Все люди, компании, заказы и суммы — демонстрационные.

## Запуск

Без сборки и зависимостей. Нужен любой статический сервер (из-за загрузки медиа и localStorage лучше не открывать файл напрямую).

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 5173
```

Затем открыть http://localhost:5173/. Подойдёт и `npx serve`, `python -m http.server` — что есть под рукой.

Автотесты расчётов и переходов состояний: http://localhost:5173/tests.html (работают на копии демо-данных в памяти, состояние прототипа не меняют).

```

assets/css/components.css  кнопки, поля, чипы, статусы, медиа-кадр, таблицы, вкладки, этапы, модальные окна, уведомления
assets/css/site.css        маркетинговые страницы (главная, подвал, полоса прототипа)
assets/css/app.css         кабинеты: каталог, профиль, заказ, кампании, конструктор, сообщения
assets/js/config.js        название сервиса и параметры расчёта (сбор, доставка, правки, сроки)
assets/js/terms.js         условия заказа: снимок условий кампании, этапы, сроки (календарные/рабочие дни), бюджет
assets/js/media.js         реестр фото/видео с источниками и лицензиями
assets/js/data.js          связанный демо-набор: 11 креаторов с услугами и портфолио, 5 кампаний (cmp4 — с публикацией,
                           cmp5 — закрыта), предложения, заказы, обращение №3001, заявки и документы на проверке
assets/js/store.js         состояние в localStorage (ключ ugc-prototype-v2) + селекторы
assets/js/flow.js          рабочий процесс: предложения и отклики, оплата → отправка → получение → сдача → правки →
                           приёмка → публикация → выплата, повторный заказ, обращения, модерация
tests.html                 автотесты расчётов и переходов
assets/js/ui.js            форматирование, медиа, модальные окна (<dialog>), уведомления, валидация
assets/js/app.js           hash-маршрутизация, оболочки «сайт» и «кабинет», русская типографика
assets/js/pages/*.js       страницы
```

## Маршруты

| Адрес | Экран |
|---|---|
| `#/` | Главная |
| `#/creators` | Каталог креаторов (фильтры и сортировка в адресе) |
| `#/creators/c1` | Профиль креатора |
| `#/creators?fmt=publish` | Каталог в режиме «С публикацией» (цены услуг публикации) |
| `#/creators/c10` | Непроверенный креатор: ограничения на заказы с отправкой товара |
| `#/orders/o-1051` | Карточка заказа (главный рабочий экран) |
| `#/orders/o-1044` | Заказ с публикацией на этапе «Публикация» |
| `#/orders` | Список заказов |
| `#/campaigns`, `#/campaigns/cmp3`, `#/campaigns/new` | Кампании, отклики, конструктор с экраном проверки |
| `#/library` | Библиотека принятых материалов с фильтрами (заказчик) |
| `#/studio` | Кабинет креатора: приглашения, «Ваш ход», открытые брифы, мои отклики |
| `#/studio/profile` | Профиль креатора: о себе, услуги и цены, портфолио |
| `#/studio/settings` | Адрес ПВЗ, реквизиты для выплат, статус проверки |
| `#/messages`, `#/messages/o-1048` | Сообщения по заказам |
| `#/payments` | Платежи / выплаты |
| `#/admin` | Модерация: заявки, проверка документов, очередь выплат, обращения |
| `#/admin/ticket/o-1046/3001` | Экран обращения: заказ, переписка, история, решение |
| `#/join`, `#/sources` | Анкета креатора, источники медиа |

Роль (заказчик / креатор / админ) переключается в тёмной полосе прототипа вверху. Там же — «Сбросить данные».

## Демо-сценарий

1. `#/creators` → «Алина Соколова» → «Посмотреть профиль» → в блоке «Заказы с этим креатором» открыть `o-1051`.
2. Роль «Креатор» → «Сдать работу» → «Добавить демо-файлы», отметить пункты брифа → «Отправить на проверку».
3. Роль «Заказчик» → «Запросить правки» (таймкод + замечание) → правка 1 из 2.
4. Роль «Креатор» → «Сдать новую версию».
5. Роль «Заказчик» → «Принять работу» → статусы «Работа принята» и «Выплата в обработке» показаны отдельно.
6. Роль «Админ» → `#/admin` → «Провести выплату» → у креатора в `#/payments` статус «Выплачено».

Оплата и выплата — **симуляция**: реальные платёжные системы не подключены.

## Что заменить при переходе к рабочей версии

- `config.js` — название сервиса и ставки (сейчас параметры прототипа).
- `media.js` — стоковые медиа на материалы реальных креаторов с подтверждёнными правами.
- `store.js` / `flow.js` — localStorage на API; каждое действие в `U.flow` соответствует будущему запросу.
